# AutoLoc

Application de gestion de location de voitures.

## Acteurs

- **Client** : consulte les véhicules et réserve une location.
- **Agent d'agence** : gère les locations et les retours de véhicules.
- **Responsable d'agence** : supervise l'agence et suit l'activité.
- **Administrateur** : gère les utilisateurs et la configuration du système.

## Cas d'utilisation

### Client
- S'inscrire / se connecter
- Consulter les véhicules disponibles
- Réserver un véhicule
- Annuler une réservation

### Agent d'agence
- Enregistrer une location
- Enregistrer le retour d'un véhicule
- Gérer les clients

### Responsable d'agence
- Gérer le parc de véhicules
- Consulter les statistiques de l'agence

### Administrateur
- Gérer les comptes utilisateurs
- Gérer les agences
